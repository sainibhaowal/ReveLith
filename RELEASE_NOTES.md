# ReveLith release notes: v0.9.4 to v0.11.2

This is the consolidated change list from **v0.9.4** (August 31, 2026) through **v0.11.2** (October 18, 2026). It is not a list of changes made after v0.11.2. Source and test links are pinned to the v0.11.2 tag so each entry can be checked against the code included in that release.

Compare: [v0.9.4 to v0.11.2](https://github.com/sainibhaowal/ReveLith/compare/v0.9.4...v0.11.2)

## Highlights

- The visible app lineup expanded to nine apps: Docs, Sheets, Slides, PDF, Markdown, HTML, Forms Builder, Tasks, and Draw.
- Document, spreadsheet, presentation, PDF, and Markdown editing gained substantial new editing, conversion, performance, and file-fidelity work.
- HTML, Forms Builder, Tasks, and Draw gained dedicated authoring apps and workflows.
- AI assistance expanded across editors, with configurable provider settings, in-document research and citations, command-line operations, and MCP access.
- Desktop packaging, release asset handling, and deployment of the website to the VPS were updated.
